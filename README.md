# 🧭 YatraSarathi – Your AI-Powered Travel Companion 🌍

## ✨ Overview  
**YatraSarathi** is a modern web platform designed to make travel planning **smart, personalized, and sustainable**.  
It helps travelers create customized itineraries, discover hidden gems, and support local communities — all through a seamless, visually rich experience.  

Built with **React**, **Tailwind CSS**, and **Framer Motion**, it offers elegant glassmorphism UI, smooth animations, and full responsiveness across devices.  

---

## 🚀 Features  

### 🌟 Core Highlights  
- 🗺️ **Personalized Itineraries** — Generate day-by-day plans based on your interests and budget.  
- 💸 **Budget-Friendly Planning** — Smart suggestions for transport, food, and stay.  
- 🌿 **Sustainable Tourism** — Explore eco-conscious and offbeat destinations.  
- 🧑‍🤝‍🧑 **Local Community Support** — Promote rural and small-business tourism.  

### 💻 UI & UX
- 🌈 Glassmorphism-based **modern interface**  
- 🎨 **Gradient theme (Orange → White → Green)** inspired by Indian spirit  
- ✨ **Smooth animations** with Framer Motion  
- 📱 **Fully responsive** design for all screen sizes  
- 🔗 **Interactive navbar, hero, features, and footer sections**

## 🧩 Tech Stack  

| Technology | Purpose |
|-------------|----------|
| ⚛️ **React 19** | Frontend framework |
| 🎨 **Tailwind CSS v4** | Styling and design system |
| 🗺️ **Leaflet** | Spatial route visualization |
| 💫 **Motion** | Animations and accessible transitions |
| 🧰 **Lucide React** | Icons and visual indicators |
| 🌐 **Vite 7** | Frontend bundler and dev server |
| 🤖 **Google Gemini (Server-Side)** | AI Travel Intelligence layer |

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Local Development
```bash
npm run dev
```

### 3. Production Build & Local Preview
```bash
npm run build
npm run preview
```

### 4. Standalone Production Server
```bash
npm run build
npm start
```
*Runs a zero-dependency production Node.js server serving the application shell and `/api/plan` on `http://localhost:3000`.*
